# MERN Stack File Upload Using ImageKit and Multer

This repository is dedicated to learning and practicing file uploads in the MERN Stack (MongoDB, Express.js, React.js, and Node.js) using Multer and ImageKit.

The project demonstrates how to handle file uploads from a React frontend, process uploaded files using Multer in an Express.js backend, and store images in ImageKit cloud storage. It also explores how to retrieve image URLs and save file information in MongoDB.

### Technologies Used

- React.js – Frontend user interface
- Node.js – Backend runtime environment
- Express.js – REST API development
- MongoDB – Database for storing image metadata and URLs
- Multer – Handling multipart/form-data file uploads
- ImageKit – Cloud-based image storage and delivery

### Learning Objectives

- Understand file uploads in the MERN Stack.
- Implement Multer middleware for handling uploaded files.
- Upload images directly to ImageKit cloud storage.
- Manage image URLs and file IDs.
- Store uploaded image information in MongoDB.
- Build and test file-upload REST APIs.
- Practice frontend and backend integration.

This repository serves as a hands-on learning project to understand file handling, cloud image storage, and full-stack development using the MERN Stack.
